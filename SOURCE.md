# Source and relinking materials

The complete sanitized corresponding source is provided as a release attachment,
not as Git submodules or an upstream-history mirror in this repository.
Download both the corresponding-source and ARM64 relink-inputs archives from the
same 0.17 release. Verify SHA256SUMS.txt before extracting. See BUILDING.md and the
README, license files, manifest.json and verification.json inside those archives.
